# 🔬 Scientific Calculator

A responsive and interactive Scientific Calculator built using HTML, CSS, and JavaScript. It provides a simple interface for performing arithmetic and scientific calculations.

## 🚀 Live Demo

[**Open Scientific Calculator**](YOUR_GITHUB_PAGES_URL)

## ✨ Features

- Basic arithmetic: Addition, Subtraction, Multiplication and Division
- Percentage calculations
- Square root and powers
- Trigonometric functions
- Logarithmic calculations
- Clear and delete operations
- Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
